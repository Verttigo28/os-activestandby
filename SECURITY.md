# Security policy

## Supported versions

The latest release receives fixes. Upgrade with the guided upgrade (Operations tab) or by installing the new package on both nodes.

## Reporting a vulnerability

Please report privately, not as a public issue:

- GitHub: **Security > Report a vulnerability** on this repository, or
- e-mail the maintainer (address in `Makefile`).

Include the version, a description, steps to reproduce and the impact. You will get an acknowledgement within a few days and a fix or mitigation plan after triage.

The threat model, controls and known limits are in [docs/security.md](docs/security.md).
